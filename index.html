Hubungkan Google Drive

Pena menyimpan seluruh database cerita sebagai satu file pena-novel-database.json di Drive-mu sendiri. Untuk mengaktifkannya, kamu perlu membuat OAuth Client ID Google sekali saja (gratis).

1. Buka Google Cloud Console → Credentials
2. Buat proyek baru (atau pakai yang sudah ada)
3. Aktifkan Google Drive API di menu "Enable APIs & Services"
4. Buat kredensial → OAuth client ID → tipe Web application
5. Di "Authorized JavaScript origins", tambahkan alamat website Pena-mu (mis. https://namamu.github.io)
6. Salin Client ID yang dihasilkan, tempel di bawah ini

Client ID ini tersimpan lokal di browsermu saja, tidak dikirim ke server manapun selain Google.
